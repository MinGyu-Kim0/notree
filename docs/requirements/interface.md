# 인터페이스 요구사항

## SIR-001 음성 인식 실패 대응

외부 연계 > 음성 인식 · 필수 · 담당 김민규 · 요청 · 관련 SFR-004, QUR-003

시스템은 외부 음성 인식 장애를 감지하고 확보된 학습 기록과 실패 상태를 구분해야 한다.

**수용 기준**

1) 연결 거절·중간 단절·종료 응답 누락(종료 요청 후 10초) 사례를 확인한다.
2) 실패한 구간을 정상 전사로 표시하지 않고 누락 구간으로 기록한다.
3) STT 연결은 최초 후 3회까지 새 세션으로 다시 연결하며, 그동안 음성은 계속 저장한다. 모두 실패하면 녹음을 부분 완료로 종료한다.
4) 저장된 음성이 있는 누락 구간은 예산 안에서 자동으로 1회 재전사를 요청하고, 시도마다 비용을 미리 예약한다. 예산이 없으면 수동 재전사 버튼을 제공한다.

**비고**: [MVP] 자동 1회는 실행 요청 1회를 말하며 청구가 1회만 된다는 보장은 아니다.

## SIR-002 AI 응답 실패 대응

외부 연계 > AI 응답 · 필수 · 담당 김민규 · 요청 · 관련 SFR-007, SFR-035

시스템은 외부 AI의 지연·오류·불완전 응답을 정상 완료와 구분해야 한다.

**수용 기준**

1) 빈 응답·중단·한도 오류를 실패 또는 부분 상태로 표시한다.
2) 불완전한 결과를 확정 노트·평가로 반영하지 않는다.
3) 한도 오류는 제공사가 알려준 대기 시간을 따르고, 30초를 넘으면 대기 상태로 전환한다.

**비고**: [MVP]

## SIR-003 외부 AI 클라이언트 연동

외부 연계 > MCP · 선택 · 담당 김민규 · 요청 · 관련 SER-002

시스템은 MCP를 지원하는 외부 AI 클라이언트에서 사용자의 노트를 조회할 수 있는 연동을 제공해야 한다.

**수용 기준**

1) 사용자가 허용한 범위의 노트만 읽기 전용으로 제공한다.
2) 연동을 해제하면 접근이 차단된다.
3) 제공 범위는 노트 조회로 한정한다.

**비고**: [후속] 내부 처리에는 MCP를 쓰지 않는다.
