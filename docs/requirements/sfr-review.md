# 기능: 개인맞춤 복습

## SFR-028 복습 개념 선택

개인맞춤 복습 > 대상 선정 · 필수 · 담당 임서연 · 요청 · 관련 SFR-025, SFR-026

시스템은 노트와 학습 상태에 따라 복습할 개념을 선택해야 한다.

**수용 기준**

1) 선택한 개념과 주요 근거를 제시한다.
2) 같은 노트라도 수행 이력이 다르면 이력 근거에 따라 다른 개념을 선택한다(QUR-006 비교 사례로 확인).
3) 제공 순서는 재학습 중인 문제, 현재 기억 확률이 낮은 문제, 신규 문제 순이다.

**비고**: [MVP]

## SFR-029 문제 유형 선택

개인맞춤 복습 > 유형 선정 · 필수 · 담당 임서연 · 요청 · 관련 SFR-028

시스템은 학습 목적과 상태에 맞는 문제 유형을 선택해야 한다.

**수용 기준**

1) 지원 유형은 서술형·단답형·객관식·플래시카드이며, 학습 목적과 이해 상태에 맞는 유형을 고른다.
2) 항상 같은 형식으로 고정하지 않는다.
3) 객관식·단답형은 이해 상태의 약한 근거로만 쓰며, 이것만으로 '독립 수행 확인'이 되지 않는다.
4) 플래시카드는 사용자가 회상한 뒤 정답을 확인하고 스스로 평가한다.

**비고**: [MVP] v0.3.1의 유형 목록 미정과 '큰 영향을 주지 않는다'를 1)·3)으로 확정.

## SFR-030 문제 난이도 조절

개인맞춤 복습 > 난이도 조절 · 필수 · 담당 임서연 · 요청 · 관련 SFR-029

시스템은 사용자의 이해 상태와 최근 수행에 맞게 문제 난이도를 조절해야 한다.

**수용 기준**

1) 요구 수준을 회상·설명·구별·적용 단계로 조절한다.
2) 유형만 바꾸고 같은 요구 수준을 반복하는 경우는 난이도 변경으로 기록하지 않는다.

**비고**: [MVP]

## SFR-031 정보 부족 시 초기 복습

개인맞춤 복습 > 초기 학습 · 필수 · 담당 임서연 · 요청 · 관련 SFR-028, SFR-032

시스템은 학습 이력이 부족한 사용자에게도 복습을 제공해야 한다.

**수용 기준**

1) 정보 없음은 미평가로 표시한다.
2) 노트와 초기 정책으로 시작하며, 새 개념은 노트 기반 설명형 문제와 필요하면 짧은 진단 문제로 시작한다.

**비고**: [MVP]

## SFR-032 기본 망각 모델 적용

개인맞춤 복습 > 초기 일정 · 필수 · 담당 임서연 · 요청 · 관련 DAR-004

시스템은 관찰이 적을 때 기본 망각 모델을 복습 시점 판단에 사용해야 한다.

**수용 기준**

1) 복습 시점은 FSRS로 판단하며, 적용한 라이브러리·파라미터 버전을 식별한다.
2) 초기에는 고정된 라이브러리 버전의 기본 파라미터를 쓰고, 개인별 최적화는 하지 않는다.
3) 목표 기억 유지율 0.9, 간격 무작위 분산(fuzzing) 사용 안 함(초기값).
4) 복습 단위는 사용자·개념·학습 목표·과제 종류(회상·설명·적용·구별)·응답 방식(고르기·직접 답하기)·평가 기준 주 버전의 조합이다. 문구만 바뀐 문제는 같은 단위로 이어가고, 정답이나 목표의 의미가 바뀌면 새 단위로 시작하며 기존 단위는 이력을 남긴 채 은퇴한다.

**비고**: [MVP] FSRS 관련 '확인 필요'를 이 행으로 모음. 라이브러리 설정 지원 여부는 구현 검증 필요.

## SFR-033 개인별 복습 시점 갱신

개인맞춤 복습 > 개인 일정 · 필수 · 담당 임서연 · 요청 · 관련 SFR-032, SFR-036

시스템은 수행 결과와 시간 경과를 반영해 다음 복습 시점을 갱신해야 한다.

**수용 기준**

1) 같은 개념이라도 수행 결과가 다르면 다음 복습 간격이 달라진다.
2) 간격 유지·변경 이유를 제시한다.
3) 간격 범위: 처음 학습 1분·10분, 재학습 10분, 복습 1~180일(초기값).
4) 핵심 실패·중대 오개념·합격선 미만의 부분 정답·회상 전 정답 보기·내용 힌트 사용은 '다시(Again)'로 기록한다. 힌트 없는 성공은 기본 '보통(Good)'이며 사용자가 '어려움(Hard)'·'쉬움(Easy)'으로 바꿀 수 있다. 플래시카드는 사용자가 4단계 중 선택한다.
5) 같은 날 추가 학습도 리뷰로 기록하되, 이해 상태 승격 횟수는 SFR-025 규칙을 따른다.

**비고**: [MVP] 개인 이력에 따른 간격 보정은 후속(데이터 축적 후 확인용 세트로 평가).

## SFR-034 근거 있는 문제 생성

개인맞춤 복습 > 문제 생성 · 필수 · 담당 임서연 · 요청 · 관련 SFR-029, SFR-030, DAR-004

시스템은 선택한 개념·유형·난이도에 맞는 문제와 평가 기준을 생성해야 한다.

**수용 기준**

1) 문제·정답·평가 기준을 각각 버전으로 관리하고 근거 블록 버전과 연결한다.
2) 허용 자료로 검증되지 않은 주장을 정답으로 확정하지 않는다.
3) 새 문제는 활성화되는 순간 근거가 여전히 유효한지 원자적으로 확인하며, 확인과 활성화 사이에 바뀐 경우에도 활성화하지 않는다.

**비고**: [MVP]

## SFR-035 유형에 맞는 답안 평가

개인맞춤 복습 > 답안 평가 · 필수 · 담당 임서연 · 요청 · 관련 SFR-034, SFR-052, QUR-001

시스템은 제출 답안을 문제 유형과 평가 기준에 따라 평가해야 한다.

**수용 기준**

1) 충족·누락·부분 이해·오개념을 구분한다.
2) 서술형은 핵심 요소별 0·0.5·1점과 중대 오개념 표시, 단답형은 정답·동의어·필수 요소 일치, 객관식은 정오로 평가한다.
3) 합격선: 서술형은 필수 요소 점수 합이 필수 요소 수의 0.8배 이상이고 중대 오개념이 없을 때, 단답형은 필수 요소가 모두 맞을 때다(초기값).
4) 힌트 사용(종류 포함)과 정답 노출을 반영한다. 플래시카드에서 회상한 뒤 정답을 확인하는 것과, 서술·단답형에서 제출한 뒤 피드백을 보는 것은 정답 노출로 보지 않는다.
5) 모호한 평가는 보류하고 복습 간격에 반영하지 않으며, 24시간 안에 해결되지 않으면 확인 문제를 제안한다.
6) 채점 결과를 학습 상태에 반영하는 순간 문제 근거가 바뀌었으면(채점 도중 바뀐 경우 포함) 평가를 보류하고 반영하지 않는다.

**비고**: [MVP] v0.3.1의 부분점수·자기평가·힌트 처리 '확인 필요'를 2)~4)로 확정.

## SFR-036 평가 결과의 후속 반영

개인맞춤 복습 > 후속 판단 · 필수 · 담당 임서연 · 요청 · 관련 SFR-025, SFR-033

시스템은 복습 평가를 학습 상태와 후속 출제·일정 판단에 반영해야 한다.

**수용 기준**

1) 답안 평가와 상태 갱신·예약의 결과를 구분한다.
2) 같은 답안 재처리로 상태나 일정이 중복 갱신되지 않는다.
3) 같은 개념에 서로 다른 답안이 동시에 들어와도 갱신이 누락되지 않는다.

**비고**: [MVP]

## SFR-037 복습 일정 보관·조회

개인맞춤 복습 > 예약 · 필수 · 담당 임서연 · 요청 · 관련 DAR-004

사용자는 예정된 복습과 도래·완료 상태를 확인할 수 있어야 한다.

**수용 기준**

1) 다음 복습 시각과 대상을 확인한다.
2) 재접속·재시작 후에도 예약이 유지된다.
3) 표시 시간대는 KST로 일관된다.
4) 예정 시각과 실제 제공·리뷰 시각을 구분해 기록한다.
선택: 사용자 시간대의 설정 방식과 시간대 변경 시 일정 처리.

**비고**: [MVP] 저장은 절대 시각, 표시는 KST.

## SFR-038 예정 복습 제공

개인맞춤 복습 > 제공 · 필수 · 담당 임서연 · 요청 · 관련 SFR-037, SFR-040, SFR-055, PER-005

시스템은 저장된 복습 일정에 따라 도래한 복습을 제공해야 한다.

**수용 기준**

1) 도래한 복습은 앱의 전체 복습 목록에 즉시 표시한다.
2) '오늘의 추천 학습'은 사용자 학습 가능 시간과 개수(SFR-040) 안에서 고르고, 넘친 항목에는 다음 날 추천 예정을 표시한다.
3) 변경·취소된 이전 일정이 앱에서 중복 제공되지 않는다.
4) 메일 알림은 사용자가 켠 경우에만 하루 1회 KST 09:00에 묶어서 보낸다(기본값 꺼짐). 사용자의 Gmail 계정 권한은 요구하지 않는다.
5) 메일 발송 결과가 불확실하면 다시 보내지 않으며, 장기 중단 후에도 지난 메일을 몰아서 보내지 않는다. 메일의 링크는 항상 최신 복습 목록을 연다.
6) 캘린더 등록은 SFR-055에서 다룬다.

**비고**: [MVP] v0.3.1 대비: 'gmail, calendar'를 앱 내 목록(필수), 메일(사용자가 켤 때 발송), 캘린더(SFR-055)로 나눔. 메일 중복·누락이 0건이라고 보장하지 않는다.

## SFR-039 연기·건너뜀·미응답 처리

개인맞춤 복습 > 일정 조정 · 필수 · 담당 임서연 · 요청 · 관련 SFR-037

시스템은 복습의 연기·건너뜀·미응답을 구분해 일정을 조정해야 한다.

**수용 기준**

1) 미응답을 오답으로 기록하지 않는다.
2) 연기는 사용자가 새 날짜를 정하고, 건너뜀은 다음 날 다시 추천하며, 미응답은 도래 상태를 유지한다. 셋 다 복습 등급으로 기록하지 않는다.
3) 사용자는 특정 문제의 복습을 중단할 수 있다.
4) 다음 복습은 실제 수행 결과를 기준으로 다시 계산한다.

**비고**: [MVP]

## SFR-040 학습 가능 시간 반영

개인맞춤 복습 > 개인화 제약 · 권장 · 담당 임서연 · 요청 · 관련 SFR-028, SFR-039

시스템은 사용자가 정한 학습 가능 시간과 선호를 복습 결정에 반영해야 한다.

**수용 기준**

1) 기본 학습량은 하루 20분, 신규 5개, 복습 20개이며 사용자가 바꿀 수 있다(초기값).
2) 문제 유형별 예상 시간(서술 4분, 단답 1분, 객관식 0.5분, 카드 0.3분)으로 시간 예산을 계산한다.
3) 시간 제약을 초과하는 제공은 다음 날로 넘기며, 사용자 시간 설정이 AI 판단보다 우선한다.
4) 선호 정보가 없어도 동작한다.

**비고**: [MVP]

## SFR-041 변경된 자료의 복습 재검토

개인맞춤 복습 > 유효성 · 필수 · 담당 임서연 · 요청 · 관련 SFR-023, DAR-004

시스템은 노트나 학습 상태가 바뀌면 관련 복습의 유효성을 다시 판단해야 한다.

**수용 기준**

1) 제공·채점 전에 근거 버전을 확인하고, 무효한 문제는 제공·채점하지 않는다.
2) 유지·수정·재생성·재평가를 구분한다.
3) 근거 문구만 바뀌면 문제를 자동 갱신하고 알린다. 정답이나 학습 목표의 의미가 바뀌면 새 문제를 자동 생성·검증해 활성화하고 변경 내용을 알린다. 원자료끼리 사실이 충돌하거나 검증이 불확실하면 문제를 멈추고 사용자 확인을 받는다.
4) 과거 정답·평가는 바꾸지 않는다. 바뀐 문제와 연결된 이해 상태·일정만 다시 계산한다.
5) 대체 문제 검증에 실패하면 '문제 준비 불가'로 표시한다.

**비고**: [MVP] v0.3.1의 '확인: 수정·재생성 기준'을 3)으로 확정.

## SFR-042 복습 선택 이유 안내

개인맞춤 복습 > 설명 · 권장 · 담당 임서연 · 요청 · 관련 SFR-028, SFR-033

사용자는 복습 개념·유형·난이도·시점의 주요 선택 이유를 확인할 수 있어야 한다.

**수용 기준**

1) 판단에 사용한 관찰·노트·정책을 연결한다.
2) 내부 추론 전문 대신 주요 근거 3개를 요약해 제공한다.

**비고**: [MVP]

## SFR-052 복습 답안 제출

개인맞춤 복습 > 답안 제출 · 필수 · 담당 임서연 · 요청 · 관련 SFR-035, DAR-004

사용자는 복습 문제에 답안을 작성해 제출할 수 있어야 한다.

**수용 기준**

1) 작성 중인 답안은 마지막 입력 2초 뒤와 입력 칸을 벗어날 때 서버에 자동 저장되며, '저장 중·저장됨·오프라인 미저장'을 표시한다.
2) 서버 저장이 확인된 초안은 화면이나 기기를 옮겨도 복원된다. 앱 안에서 화면을 옮길 때는 저장 확인을 기다리거나 초안을 앱 메모리에 유지해 잃지 않는다. 저장되지 않은 상태로 앱을 떠나려 하면 경고한다.
3) 오프라인 상태에서 브라우저가 강제 종료된 경우의 초안 보존은 보장하지 않는다.
4) 다른 화면에서 동시에 고친 초안이 충돌하면 두 초안을 모두 보존하고 사용자가 고른다.
5) 문제가 바뀌면 초안을 '이전 문제 기준'으로 보관하고, 새 문제의 답으로 자동 제출하지 않는다.
6) 힌트 확인·정답 보기 여부가 제출 기록에 함께 남는다.
7) 제출 후 평가 진행·완료·보류·실패 상태를 표시한다.
8) 제출한 답안은 수정되지 않는 기록으로 보관한다.

**비고**: [MVP] 공용 기기에서 노출되지 않도록 브라우저 저장소에 초안을 남기지 않는다.

## SFR-053 평가 피드백 제공

개인맞춤 복습 > 피드백 · 필수 · 담당 임서연 · 요청 · 관련 SFR-035, SFR-011

사용자는 제출한 답안의 평가 결과와 부족한 부분을 확인할 수 있어야 한다.

**수용 기준**

1) 충족한 내용, 누락한 개념, 오개념을 구분해 보여준다.
2) 각 지적 사항에서 근거가 된 노트 위치로 이동할 수 있다.
3) 평가가 보류된 경우 그 사유를 표시한다.

**비고**: [MVP]

## SFR-055 복습 일정 캘린더 등록

개인맞춤 복습 > 외부 연동 · 선택 · 담당 임서연 · 요청 · 관련 SFR-037

사용자는 예정된 복습을 외부 캘린더나 할 일 목록에 등록할 수 있어야 한다.

**수용 기준**

1) 일정이 바뀌면 등록한 항목을 갱신하거나 갱신이 필요함을 안내한다.
2) Google 캘린더와 연동한다.
3) 등록 중 오류가 나도 같은 일정이 두 번 만들어지지 않도록, 등록 전에 이미 있는지 확인한다.

**비고**: [후속] 정책은 확정, 출시 구현은 후속.

## SFR-056 복습 기록 시각화

개인맞춤 복습 > 동기 부여 · 선택 · 담당 임서연 · 요청 · 관련 SFR-037, SFR-039

사용자는 날짜별 복습 완료 기록을 한눈에 확인할 수 있어야 한다.

**수용 기준**

1) 날짜별 완료한 복습 수를 표시한다.
2) 미응답·건너뜀·연기는 완료로 세지 않는다.

**비고**: [후속] 잔디 형태 표시 아이디어.
