# 성능 요구사항

## PER-001 전사 표시 지연 기준

응답 성능 > 전사 · 필수 · 담당 김민규 · 요청 · 관련 SFR-004, SFR-005

서비스는 합의된 사용 조건에서 발화 후 전사가 화면에 표시되기까지의 목표 시간을 충족해야 한다.

**수용 기준**

1) 네트워크·동시 녹음 수를 고정해 측정한다. 동시 녹음 10개, 60분 한·영 강의, 왕복 지연 100ms.
2) 미확정 발화의 최초 표시와 확정까지의 시간을 분리해 측정한다.
3) 초기 목표: 미확정 표시 p95 3초, 확정 p95 8초.

**비고**: [MVP] 목표치이며 측정 전. 계정의 동시 스트림 한도가 10 미만이면 허용 수로 측정. 답변 응답 기준은 PER-004로 분리.

## PER-002 최종 노트 생성 시간 기준

처리 성능 > 노트 생성 · 필수 · 담당 이근욱 · 요청 · 관련 SFR-007

서비스는 강의 종료 후 최종 노트 생성을 합의된 시간 안에 완료해야 한다.

**수용 기준**

1) 녹음 종료 조작부터 최종 노트 완료까지의 전체 시간과 세부 구간(종료 처리, STT 마무리, 대기, 생성)을 측정한다.
2) 측정 조건: 60분 강의, 지정 모델, 동시 녹음 10개.
3) 초기 목표: p95 120초.
4) 부분 완료는 완료와 분리해 집계한다.

**비고**: [MVP] v0.3.1의 '추상적으로 제시'는 채택하지 않음. 목표치이며 측정 전. 복습 제공 기준은 PER-005로 분리.
변경 제안(승인 대기): 실제 모델로 측정했을 때 p95 120초가 구조적으로 불가능하면(최종 노트 생성 경로가 120초를 넘는 경우) 기준 개정을 제안한다. 그 전에는 몰래 완화하지 않는다.

## PER-003 사용량·비용 한도 처리

운영 한도 > 사용량 · 필수 · 담당 김민규 · 요청 · 관련 QUR-004, QUR-007

서비스는 합의된 사용량과 비용 한도에 도달했을 때 정해진 동작을 제공해야 한다.

**수용 기준**

1) 재시도를 포함한 사용량과 예상 비용을 측정한다.
2) 신규 호출 허용 한도는 사용자당 하루 US$1, 전체 하루 US$10(UTC 기준, 설정 기본값)이다. 진행 중인 녹음의 예약 금액을 포함하며, 날짜가 바뀌어도 예약은 풀리지 않는다.
3) 녹음은 시작 때 고른 시간의 예상 최대 비용에 10%를 더해 예약하고, 30분 단위로 연장한다. 연장할 수 없으면 경고한 뒤 예약 시간에 정상 종료하고 자료를 보존한다.
4) 한도에 도달하면 새 녹음을 막고, AI 분석은 자료를 보존한 채 대기하며, Q&A는 즉시 한도를 안내하고 초기화 시각을 표시한다. 끝없이 대기시키지 않는다.
5) 동시 실행은 계정당 녹음 1개, Q&A 1개, AI 작업 전체 2개까지다.
6) 계정당 저장 용량은 2GiB다. 한도에 닿으면 새로 만드는 것만 막고 기존 자료는 지우지 않으며, 진행 중인 녹음은 예상 용량을 미리 예약한다.
7) 이 한도는 새 호출을 허용할지 정하는 기준이며, 청구 지연 등으로 실제 청구액이 한도를 넘지 않는다고 보장하지 않는다.

**비고**: [MVP] 금액은 실제 요금 확인 전의 설정 기본값이며 금전 집행 승인이 아니다.

## PER-004 Q&A 답변 응답 시간 기준

응답 성능 > 답변 · 필수 · 담당 임서연 · 요청 · 관련 SFR-016

서비스는 합의된 사용 조건에서 Q&A 답변의 목표 응답 시간을 충족해야 한다.

**수용 기준**

1) 참고 자료량·동시 사용자를 고정해 측정한다.
2) 답변의 최초 표시와 전체 완료를 분리해 측정한다.
3) 초기 목표: 최초 표시 p95 10초, 전체 완료 p95 60초.
4) 입력 한도는 16k 토큰(시스템 1.5k, 질문 2k, 지정 자료 4k, 검색 4k, 최근 대화 3k, 요약 1.5k), 출력 2k, 질문 1건당 누적 입력 64k·출력 6k·90초 이내다. 남는 몫은 다른 항목이 쓸 수 있고, 질문이 2k를 넘으면 나눠 입력하도록 안내하며, 자료를 자를 때는 반드시 표시한다.
5) 실패·시간 초과는 오류로 집계하고 사용자 취소는 분모에서 제외한다. 초기 목표는 오류 1% 미만, 부분 완료 5% 미만이다.

**비고**: [MVP] v0.3.1 비고의 '측정불가'는 채택하지 않음. 목표치이며 측정 전.

## PER-005 복습 제공 지연 기준

처리 성능 > 복습 제공 · 필수 · 담당 임서연 · 요청 · 관련 SFR-038

서비스는 예정 시각이 된 복습을 합의된 지연 안에 제공해야 한다.

**수용 기준**

1) 예정 시각부터 앱 복습 목록에 나타나기까지의 시간을 측정하며, 초기 목표는 p95 60초다.
2) 추천 학습 제공 시각과 실제 리뷰 시각은 별도 지표로 관찰한다.
3) 메일은 발송 시도와 제공사 접수까지만 측정하며 사용자 수신 시각은 보장하지 않는다.

**비고**: [MVP] 허용 지연은 복습 예정 시각이 지난 뒤 앱에 나타나기까지 걸리는 시간을 말한다.
