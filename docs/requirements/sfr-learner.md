# 기능: 학습자 상태

## SFR-024 학습 관찰 추출

학습자 상태 > 관찰 추출 · 필수 · 담당 임서연 · 요청 · 관련 DAR-003, SER-001

시스템은 질문과 복습 수행에서 개념별 학습 관찰을 추출해야 한다.

**수용 기준**

1) 관찰에는 질문 원문을 넣지 않고 개념·관찰 결과·시점·근거 유형만 남긴다. 질문 원문은 대화 기록에만 보관한다(SER-001).
2) AI의 설명을 사용자의 성취로 기록하지 않는다.
3) 단순 질문은 관찰로 기록하지 않는다. 사용자가 오개념을 단정적으로 말하거나 이해하지 못했다고 밝힌 경우만 약한 관찰로 기록한다.

**비고**: [MVP] v0.3.1 대비: 질문 원문은 대화 기록으로 보관하기로 바뀌었지만, 관찰에는 여전히 넣지 않는다.

## SFR-025 근거에 따른 이해 상태 갱신

학습자 상태 > 상태 갱신 · 필수 · 담당 임서연 · 요청 · 관련 DAR-003, QUR-004

시스템은 누적 학습 관찰에 따라 개념별 이해 상태를 갱신해야 한다.

**수용 기준**

1) 이해 상태는 미평가·학습 중·독립 수행 확인·재확인 필요의 4단계다.
2) '독립 수행 확인'은 최근 60일 안에 서로 다른 날, 힌트 없이 서술·응용 문제의 핵심 요소를 충족한 성공이 2회일 때 부여한다. 처음 부여할 때도 마지막 강한 실패 이후의 성공만 세며, 같은 KST 날짜의 여러 성공과 같은 답안의 재제출은 1회로 센다.
3) 한 번 확인되면 새 강한 실패, 근거 무효, 마지막 독립 성공 후 90일 경과 중 하나가 생길 때까지 유지하고, 생기면 '재확인 필요'로 바꾼다. 회복하려면 그 뒤 다른 날 독립 성공 2회가 필요하다.
4) 객관식·단답형·자기평가·Q&A 관찰만으로는 '독립 수행 확인'이 되지 않는다.
5) 질문만으로 상태를 낮추지 않는다.
6) 힌트·정답 노출·독립 수행·시간 경과를 구분한다.
7) 같은 관찰을 중복 반영하지 않는다.
8) 복습 관찰은 해당 복습 문제와, Q&A 관찰은 해당 대화와 함께 삭제·복원된다.
9) 개념과 이해 상태는 과목마다 따로 둔다. 같은 이름의 개념이라도 과목이 다르면 상태를 따로 계산한다.

**비고**: [MVP] 60일·90일·2회는 초기 정책값. v0.3.1의 '척도 생성'과 '유효기간'을 1)~3)·8)로 확정. v0.4.3: 개념·이해 상태의 범위를 과목으로 정함(9), ADR-0015).

## SFR-026 Q&A·복습의 상태 공유

학습자 상태 > 공유 · 필수 · 담당 임서연 · 요청 · 관련 SFR-025, SER-002

질의응답과 복습은 같은 학습자의 최신 개념별 상태를 활용해야 한다.

**수용 기준**

1) 최신 복습 결과와 이해 상태가 다음 질문의 설명 수준 결정에 사용된다.
2) Q&A에서 얻은 관찰이 이해 상태와 복습 개념 선택에 사용된다. 복습 간격(FSRS)에는 사용하지 않는다.
3) Q&A에서 오개념이 관찰되면 확인 문제 1개를 제안한다.

**비고**: [MVP]

## SFR-027 판단 확인·재평가

학습자 상태 > 정정 · 필수 · 담당 임서연 · 요청 · 관련 SFR-025, DAR-003

사용자는 이해 상태와 주요 근거를 확인하고 잘못된 판단의 재평가를 요청할 수 있어야 한다.

**수용 기준**

1) 정정 요청과 재평가 결과를 구분한다.
2) 재평가는 보관된 제출 답안으로 같은 평가 기준에서도 다시 채점할 수 있으며, 이전 평가를 대체하는 새 평가 버전으로 기록한다.
3) 재평가는 같은 수행에 대해 3회까지 요청할 수 있다(초기값).
4) 답안이 없는 예외 상황에서는 새 확인 문제로 재평가한다.
5) 정정 요청이 실제 수행 근거와 다르면 근거를 보여주고 재평가 진행 여부를 묻는다.

**비고**: [MVP] v0.3.1 대비: 제출 답안을 보관하기로 해 같은 답안 재채점이 기본 경로(DAR-004).
