# 기능: 강의 학습 (녹음·전사·노트 생성)

## SFR-001 과목·강의 맥락 관리

강의 학습 > 학습 맥락 · 필수 · 담당 김민규 · 요청 · 관련 SFR-004

사용자는 강의가 속한 과목과 배경·전문용어를 설정하고 다시 사용할 수 있어야 한다.

**수용 기준**

1) 저장한 과목·강의 맥락(배경 설명, 전문용어)을 다시 선택한다.
2) 맥락은 버전으로 관리하고, 녹음 세션 시작 시점의 최신 버전을 그 녹음 세션에 고정한다. 한 강의에 녹음 세션이 여럿이면 세션마다 시작 시점의 버전을 쓰며, 전사 구간마다 사용한 버전을 기록한다.
3) 맥락을 바꾸면 다음 녹음 세션부터 적용하며, 화면에 적용 시점을 표시한다. 녹음 중 즉시 적용은 SFR-046 3)을 따른다. 이미 끝난 강의는 재작성(SFR-015)을 요청할 때만 새 맥락을 쓴다.

**비고**: [MVP] 전문용어 목록 상한은 SFR-046 참고. v0.4.2: 맥락 버전 고정 단위를 강의에서 녹음 세션으로 변경(ADR-0002).

## SFR-002 녹음 시작·종료

강의 학습 > 녹음 · 필수 · 담당 김민규 · 요청 · 관련 SFR-004, QUR-003, COR-004, PER-003

사용자는 강의 녹음을 시작하고 종료할 수 있어야 한다.

**수용 기준**

1) 마이크 권한 거절과 연결 실패를 원인별로 표시한다.
2) 녹음 시작 전에 STT 예약 시간(1·2·3시간 중 선택, 기본 60분, 과목별 마지막 선택 기억)을 정한다.
3) 종료하면 STT 확정 응답을 기다리는 종료 처리 상태를 거쳐 확보된 마지막 발화까지 처리하고, 완료·부분 완료·실패를 구분한다.
4) 녹음 세션은 일시정지를 포함해 최대 180분이며, 예약 시간이나 세션 상한에 도달하기 10분·1분 전에 경고하고 정상 종료한다.
5) 다른 기기에서도 소유자가 진행 중인 녹음을 강제 종료할 수 있다.
6) 한 강의에 녹음 세션을 여러 개 이어 붙일 수 있다. 녹음 세션이 끝난 뒤에도 같은 강의에서 새 녹음 세션을 시작할 수 있으며, 예약 시간·180분 상한·비용 예약은 녹음 세션마다 적용한다.

**비고**: [MVP] 예약 시간에 맞춘 자동 종료는 사용자가 정한 비용 상한을 지키기 위한 선택이며, 종료 시점까지의 자료는 보존한다. v0.4.2: 강의 하나에 녹음 세션 여러 개(6), ADR-0002).

## SFR-003 일시정지·재개

강의 학습 > 녹음 · 권장 · 담당 김민규 · 요청 · 관련 SFR-002

사용자는 같은 강의에서 녹음을 일시정지하고 재개할 수 있어야 한다.

**수용 기준**

1) 정지·재개 구간을 '의도적 정지'로 기록하며 오류로 인한 누락 구간과 구분한다.
2) 정지 중에는 음성을 수집하지 않고, 재개 후 내용을 같은 강의에 연결한다.
3) 정지 중에는 연결 끊김 자동 종료(5분)를 적용하지 않는다. 단, 세션 전체 180분 상한에는 정지 시간이 포함된다.

**비고**: [MVP] 5분 이하 정지는 STT 세션을 유지하고, 더 길면 재개 때 새 STT 세션을 연다(제공사 keepalive 동작 확인 필요).

## SFR-004 한·영 혼합 실시간 전사

강의 학습 > 전사 · 필수 · 담당 김민규 · 요청 · 관련 SFR-001, PER-001, SIR-001

시스템은 한국어·영어가 섞인 강의를 실시간으로 전사해야 한다.

**수용 기준**

1) 확정·미확정 발화를 구분해 표시한다.
2) 원문 언어와 과목 전문용어를 유지한다.
3) 확정 발화는 STT의 발화 종료 신호를 받을 때 한 구간으로 묶어 저장한다. 종료 신호 없이 15초가 지나거나 일시정지·녹음 종료·STT 세션 교체가 일어나면 그때까지를 한 구간으로 닫아 저장한다(초기값).
4) STT 재연결·교체 경계에서 중복 여부가 불확실한 구간은 '중복 가능'으로 표시한다.
5) 구간을 닫은 뒤 1초를 넘겨 저장된 구간은 '저장 지연'으로 기록하고, 끝내 저장하지 못한 구간(누락 구간)과 구분해 표시한다. 실시간 서버가 비정상 종료되어 저장하지 못한 열린 구간은 누락 구간으로 기록하며, 음성이 있으면 SIR-001 4)에 따라 재전사한다.

**비고**: [MVP] v0.4.3: 저장 단위를 1초 묶음에서 발화 단위로 변경(3)·5)). 음성은 5초 단위로 따로 저장되어, 잃은 전사는 재전사로 복구할 수 있다. 화면 표시는 저장과 별개라 PER-001에 영향 없음.

## SFR-005 한·일 혼합 실시간 전사

강의 학습 > 전사 · 선택 · 담당 김민규 · 요청 · 관련 SFR-001, PER-001

시스템은 한국어·일본어가 섞인 강의를 실시간으로 전사해야 한다.

**수용 기준**

1) 확정·미확정 발화를 구분한다.
2) 원문 언어와 전문용어를 유지한다.
3) SFR-004와 같은 저장·재연결 규칙을 따른다.

**비고**: [후속] 언어 설정만 추가하는 확장. 정책은 확정.

## SFR-006 실시간 요약 노트

강의 학습 > 노트 생성 · 필수 · 담당 이근욱 · 요청 · 관련 SFR-004, DAR-001

시스템은 강의 진행 중 주요 내용을 실시간 요약 노트로 제공해야 한다.

**수용 기준**

1) 생성 중·완료·실패를 구분한다.
2) 요약 항목마다 해당 강의 전사 구간으로 이동할 수 있다.
3) 반복·보완·정정을 라벨로 구별한다.
4) 요약은 아직 요약하지 않은 확정 전사가 있을 때만 만든다. 공백 제외 100자(가능하면 발화 경계에서 확인), 가장 오래된 미요약 확정 전사의 대기 20초, 녹음 종료 시 남은 부분 중 먼저 오는 조건에서 시작하며, 무음 구간에서는 만들지 않는다(초기값).
5) 강의당 요약 작업은 실행 1개와 대기 1개로 제한한다. 새 전사가 덧붙는 것만으로 진행 중인 작업을 취소하지 않는다.
6) 실시간 요약은 녹음 중 화면에 보여 주는 임시 결과로 영구 저장하지 않는다. 최종 노트가 발행되면 지우며, 서버가 재시작되면 사라질 수 있다. 전사 정정은 실시간 요약에 다시 반영하지 않고 최종 노트에 반영한다.

**비고**: [MVP] 100자·20초는 조정 가능한 초기 정책값. v0.4.3: 실시간 요약을 영구 저장하지 않는 임시 결과로 정함(6)), 전사 수정 시 재요약 조항 삭제(5)).

## SFR-007 강의 최종 노트

강의 학습 > 노트 생성 · 필수 · 담당 이근욱 · 요청 · 관련 SFR-004, SFR-043, QUR-001

시스템은 강의 종료 후 확보된 전사문 원자료에 근거한 최종 노트를 생성해야 한다.

**수용 기준**

1) 개념·예시·복습 포인트·확인 필요 내용을 구분한다.
2) 빈 자료는 완료로 표시하지 않는다.
3) 일부 구간이 누락되거나 실패한 결과는 '부분 완료'로 표시하고, 노트 끝에 누락 구간과 사유를 적어 사용자에게 알린다.
4) 최종 노트는 실시간 요약과 별도 단계로, 같은 구간까지 요약되었더라도 반드시 생성·발행한다.
5) 근거 전사의 삭제·이동·수정 여부는 발행이 반영되는 순간 원자적으로 확인한다. 확인한 뒤 반영하기 전에 바뀐 경우에도 바뀐 근거로 만든 결과는 반영하지 않고, 해당 부분을 다시 계산한다.
6) 최종 노트는 녹음 세션이 끝날 때마다 그 강의의 확정 전사 전체로 새 버전을 생성·발행하며, 그 강의에서 마지막으로 적용된 맥락 버전을 쓴다. 새 버전은 과목 노트에 다시 반영한다.

**비고**: [MVP] v0.4.2: 녹음 세션 종료마다 새 버전(6) 추가. 수정 제안은 SFR-058.

## SFR-046 전사문 수정

강의 학습 > 전사 · 권장 · 담당 김민규 · 요청 · 관련 SFR-001, SFR-004, SFR-006, DAR-002

사용자는 실시간 전사중 전사문의 오류를 수정할 수 있어야 한다.

**수용 기준**

1) 사용자가 고친 전사문은 정정 버전으로 즉시 저장하고, 원래 STT 결과도 보존한다. 정정이 확정되고 7일이 지나면 그 구간의 STT 원본을 삭제하며(초기값), 그 전에는 원본으로 되돌릴 수 있다. 원본을 근거로 쓰던 노트 블록은 근거를 정정 버전으로 옮기고 '갱신 필요'를 유지한다('출처 삭제됨'으로 처리하지 않는다). 사용자가 '노트에 반영'을 누르면 '갱신 필요' 블록만 다시 생성한다. 수정 제안(SFR-058)을 수락한 정정의 노트 반영은 SFR-058 5)를 따른다.
2) 수정 내용에서 전문용어 후보를 뽑아, 사용자가 확인한 것만 과목 용어 목록에 추가한다.
3) 추가한 용어는 다음 녹음 세션부터 적용한다. 녹음 중에 사용자가 '용어 적용'을 누르면 새 용어로 STT 세션을 교체해 즉시 적용한다. 교체 구간은 2초 겹쳐 넘겨받고 경계는 '중복 가능'으로 표시하며, 교체 간격은 최소 60초이고(초기값), 새 STT 세션 연결에 실패하면 기존 세션을 유지한다.
4) 용어 목록은 과목당 200개, 용어당 40자, 합계 4,000자 이내다(초기값).
5) 지난 구간 재전사는 사용자가 요청하고, 음성 보관 기간 안이며, 예산이 있을 때만 한다.

**비고**: [MVP] v0.3.1 대비: '자동으로 terms로 넘긴다'를 후보 추출과 사용자 확인으로 변경. 문장 전체를 넘기면 개인정보가 섞이고 길이가 낭비된다.
v0.4.2: STT 제공사가 세션 중 용어 갱신을 지원하지 않는 것으로 보여, 녹음 중 적용은 STT 세션 교체로 한다(3), ADR-0003). 정정 후 STT 원본 7일 뒤 삭제(1)) 추가.
v0.4.3: 직접 정정의 노트 반영은 '노트에 반영' 버튼으로 유지하고, 수정 제안 수락분은 검토 완료 시 자동 반영(SFR-058 5)).

## SFR-054 녹음 파일 업로드

강의 학습 > 녹음 · 선택 · 담당 김민규 · 요청 · 관련 SFR-007, DAR-001

사용자는 녹음된 강의 파일을 올려 전사와 노트 생성을 요청할 수 있어야 한다.

**수용 기준**

1) 지원하지 않는 형식이나 길이·크기 초과는 업로드 전에 안내한다.
2) 업로드한 파일도 실시간 녹음과 같은 노트 생성 흐름을 거친다.
3) 지원 형식은 mp3, 최대 180분·200MiB다(초기값, STT 제공사 한도가 더 낮으면 낮춘다).
4) 업로드 완료 시각을 녹음 종료로 보고 음성 7일 보관을 적용한다.

**비고**: [후속] 정책은 확정, 출시 구현은 후속. 녹음 중 끊긴 구간의 복구 업로드와 저장된 음성 재전사는 이 항목과 별개로 MVP(QUR-008·SIR-001).

## SFR-057 실시간 번역 표시

강의 학습 > 번역 · 선택 · 담당 김민규 · 요청 · 관련 SFR-004, SFR-005

시스템은 전사 내용을 사용자가 선택한 언어로 번역해 함께 표시해야 한다.

**수용 기준**

1) 원문과 번역문을 구분해 표시한다.
2) 번역문을 노트 근거로 사용하지 않는다.
3) 번역문은 Q&A·출제·채점 근거로도 쓰지 않는다.
선택: 일본어, 영어, 한국어

**비고**: [후속] 프로토타입에서 일본어 번역을 시험함.

## SFR-058 오인식 의심 구간 수정 제안

강의 학습 > 전사 · 권장 · 담당 김민규 · 요청 · 관련 SFR-007, SFR-009, SFR-046, DAR-002, PER-003

시스템은 최종 노트를 만들 때 오인식이나 어색한 표현으로 추정되는 전사 구간을 찾아 사용자에게 수정을 제안해야 한다.

**수용 기준**

1) 수정 제안은 최종 노트를 생성할 때만 만들며, 실시간 요약에서는 만들지 않는다.
2) 제안마다 대상 전사 구간, 원문, 고친 문구, 이유(오인식 의심·어색한 표현)를 보여준다.
3) 실제 전사에 없는 구간을 가리키는 제안은 표시하지 않는다.
4) 사용자는 제안을 수락·거절하거나 직접 고칠 수 있다. 수락하면 전사 정정(SFR-046)처럼 정정 버전으로 저장하고 용어 후보를 뽑는다. 거절하면 전사와 노트를 그대로 둔다.
5) 수락한 정정은 사용자가 남은 제안을 모두 처리하거나 '검토 완료'를 누르면 한꺼번에 노트에 반영한다. 그 정정을 근거로 쓰는 블록만 다시 생성해 새 최종 노트 버전으로 발행하고 과목 노트에 다시 반영한다. 사용자가 편집한 블록은 자동으로 바꾸지 않고 '확인 필요'로 둔다(SFR-009 4)).
6) 거절한 제안은 같은 구간에 다시 제안하지 않는다.

**비고**: [MVP] v0.4.2 신설. 제안은 최종 노트를 만드는 같은 AI 호출에서 함께 만든다(추가 호출 없음). v0.4.3: 수락분은 '노트에 반영' 버튼 대신 검토 완료 시 자동 재생성(5)). 재생성은 추가 AI 호출이며 비용 예약(PER-003)을 따른다.
