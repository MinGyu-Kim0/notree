# 기능: 계정

## SFR-044 로그인·로그아웃

계정 > 인증 · 필수 · 담당 김민규 · 요청 · 관련 SER-002

사용자는 자신의 계정으로 로그인하고 로그아웃할 수 있어야 한다.

**수용 기준**

1) 로그인한 사용자 자신의 자료만 표시된다.
2) 로그아웃하면 해당 기기의 인증이 서버에서 철회되고, 이전 인증으로 API·실시간 연결·파일 다운로드에 접근할 수 없다.
3) 녹음 중 로그아웃하면 수집을 멈추며, 서버에 아직 저장되지 않은 음성이 손실될 수 있음을 먼저 경고한다.
4) 서버에서 진행 중인 노트 생성·Q&A·업데이트는 계속되며, 다시 로그인하면 결과를 조회할 수 있다.
5) 모든 기기에서 한 번에 로그아웃할 수 있다.
6) 철회 시점은 로그아웃이 서버에 확정(커밋)된 순간이다. 그 뒤의 새 요청·새 전송 묶음·새 저장은 허용하지 않는다. 그 전에 이미 허가되어 전송 중인 마지막 묶음(음성 최대 250ms 또는 다운로드 청크 1개, 초기값)과 이미 전송된 데이터는 회수할 수 없음을 안내한다.
7) 철회 처리가 끝나기 전에는 '처리 중'으로 표시하고, 지연되면 완료로 표시하지 않는다.

**비고**: [MVP] 이미 기기에 내려받은 파일은 회수할 수 없음을 고지한다.

## SFR-045 계정 삭제

계정 > 탈퇴 · 권장 · 담당 김민규 · 요청 · 관련 SFR-044, DAR-006

사용자는 계정을 삭제하고 자신의 학습 자료를 모두 지울 수 있어야 한다.

**수용 기준**

1) 삭제 전 삭제 대상과 복구 가능 기간을 안내한다.
2) 탈퇴를 요청하면 즉시 모든 기기의 세션을 철회해 복구 화면 외의 접근과 새 작업을 막고, 진행 중인 녹음·노트 생성·Q&A·업데이트를 취소하며 늦게 끝난 결과는 반영하지 않는다. 로그아웃(SFR-044)과 달리 서버 작업도 계속하지 않는다. 7일간 계정 복구를 유예하며, 그동안 알림과 예약 작업을 멈춘다.
3) 유예 중 복구하면 탈퇴로 인한 삭제만 취소되고, 휴지통에 있던 자료는 원래 보관 기한을 유지한다. 탈퇴로 취소된 작업은 자동 재개하지 않는다.
4) 7일이 지나면 노트·원문·음성·대화·학습 상태·복습 일정·휴지통 자료를 모두 삭제한다. 백업에는 최대 약 3주 더 남을 수 있으나 어떤 복원에서도 다시 나타나지 않음을 안내한다.
5) 내용이 없는 삭제 기록(내부 ID·시각)은 실제 삭제 후 30일간 보관해, 백업을 복원해도 계정이 되살아나지 않게 한다.

**비고**: [MVP] v0.3.1 대비: '사용자 정보는 1달 남긴다'를 2)~5)로 대체(목적이 정해지지 않은 1달 보관 폐지). 삭제 기록의 개인정보 성격은 법률 확인 필요.
