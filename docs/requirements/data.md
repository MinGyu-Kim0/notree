# 데이터 요구사항

## DAR-001 자료별 상태와 맥락 보존

학습 자료 > 보관 · 필수 · 담당 김민규 · 요청 · 관련 SFR-004, SFR-011

시스템은 강의 원자료와 노트의 소속·생성 상태·출처를 함께 관리해야 한다.

**수용 기준**

1) 다른 강의의 내용이 섞이지 않는다.
2) 확정 원문과 생성 중 결과를 구분해 복원한다.
3) 원본 음성은 녹음 세션 종료 7일 후에 만료된다. 만료 시각부터 접근·재전사·복원을 막고, 실제 삭제는 24시간 안에 끝내는 것을 목표로 한다. 재전사·재처리·복원으로 만료 시각이 늦춰지지 않는다.
4) 녹음 세션 종료 시각은 사용자의 종료, 예기치 않은 연결 끊김 후 5분 경과, 세션 180분 상한 중 먼저 오는 시각이다.
5) 음성은 서버에 내구 저장되고 재생 가능함이 확인된 뒤에만 '서버 저장됨'으로 표시하며, 마지막 서버 저장 시각을 보여준다.
6) 서버 저장이 30초 넘게 지연되면 경고하고, 브라우저 보관 한도(60초 또는 32MiB)에 도달하면 녹음을 중지한다.
7) '원본 음성'은 앱이 수집해 서버로 보낸 16kHz 모노 PCM을 말한다. 기기 입력을 그대로 무손실 보존한다는 뜻은 아니며, 품질은 시험으로 확인한다.

**비고**: [MVP] 음성 저장 단위와 코덱은 통합 시험으로 결정. STT 제공사 측 보관은 계약 확인 필요.

## DAR-002 내용 식별과 버전 보존

학습 노트 > 버전 · 필수 · 담당 이근욱 · 요청 · 관련 SFR-010, SFR-019

시스템은 노트의 내용 위치와 버전·변경 근거를 식별할 수 있어야 한다.

**수용 기준**

1) 위치 이동 후에도 같은 내용을 추적한다(고정 블록 식별자).
2) 변경 전후·출처·변경 이유를 연결한다.
3) 강의 원문과 보완 노트를 구분한다.
4) STT 원본, 사용자 전사 정정, 강의 노트 편집, 과목 노트 변경을 서로 다른 버전 계열로 보관한다. 단, STT 원본은 정정 버전이 생기면 SFR-046 1)의 기간이 지난 뒤 삭제된다.

**비고**: [MVP]

## DAR-003 관찰과 이해 상태 분리

학습자 상태 > 관찰·추정 · 필수 · 담당 임서연 · 요청 · 관련 SFR-025, SER-001

시스템은 학습 관찰과 그로부터 추정한 이해 상태를 구분해 보관해야 한다.

**수용 기준**

1) 개념·시점·근거 유형·노출 조건(힌트·정답 보기)·불확실성을 식별한다.
2) 관찰에 질문 원문이나 개인정보를 다시 기록하지 않는다.
3) 관찰은 수정하지 않고, 재평가 시 이전 관찰을 '대체됨'으로 표시한다. 이해 상태는 유효한 관찰로 다시 계산한다.
4) 관찰의 보존 기간은 출처를 따른다. 복습 관찰은 해당 복습 문제, Q&A 관찰은 해당 대화와 같다.

**비고**: [MVP] v0.3.1의 '유효기간은 복습 문제와 동일'을 4)로 구체화.

## DAR-004 출제·평가·일정 연결

복습 > 문제·평가 · 필수 · 담당 임서연 · 요청 · 관련 SFR-035, SFR-037

시스템은 복습 문제·평가 기준·시도·일정을 출제 당시 자료와 연결해야 한다.

**수용 기준**

1) 어느 문제 버전·평가 기준으로 평가했는지 식별한다.
2) 평가 뒤 노트 수정이 과거 기록을 바꾸지 않는다.
3) 과목 노트와 동일하게 저장하고 보존한다.
4) 제출 답안 원문을 보관하며, 재평가는 새 평가 버전으로 추가한다.

**비고**: [MVP] v0.3.1 비고의 '답안 원문 저장 여부' 확인 항목을 보관으로 결정.

## DAR-005 검색 자료 최신성 관리

검색 > 최신성 · 필수 · 담당 임서연 · 요청 · 관련 SFR-023, SER-002

시스템은 검색 자료를 원자료의 소유자와 현재 버전에 연결해야 한다.

**수용 기준**

1) 수정·삭제·이동된 내용을 현재 근거로 사용하지 않는다. 검색 자료가 늦게 갱신되어도 사용 시점에 원자료 상태와 권한을 다시 확인한다.
2) 갱신 중·실패 상태를 구분한다.
3) 파생 검색 자료를 다시 생성할 수 있다.
4) 내용이 덧붙기만 한 전사는 이미 확인한 앞부분을 무효로 보지 않는다.

**비고**: [MVP]

## DAR-006 삭제 영향 범위 관리

정보 관리 > 삭제 · 필수 · 담당 김민규 · 요청 · 관련 SFR-013, DAR-005

시스템은 자료 삭제에 따른 검색·복습·학습 상태의 처리 범위를 일관되게 적용해야 한다.

**수용 기준**

1) 승인된 삭제 범위의 대상이 재조회·신규 판단에 사용되지 않는다.
2) 남겨야 하는 이력과 제거할 정보를 구분한다.
3) '과목 삭제'는 과목 노트, 현재 소속된 강의 원자료·강의 노트, 대화, 문제, 답안, 관찰, 일정, 검색 자료를 한 묶음으로 삭제한다. 이미 따로 삭제된 항목과 다른 과목으로 이동한 강의는 포함하지 않는다.
4) 강의 노트 삭제 시 그 강의를 근거로 한 복습 문제를 삭제한다. 다른 출처도 근거로 쓰는 문제는 남은 출처만으로 모든 필수 평가 요소가 뒷받침되는지 문항 단위로 판정한다. 뒷받침되면 기존 문항은 제공을 멈추고 남은 출처만으로 만든 새 문항으로 바꾸며, 학습 목표·응답 방식·평가 기준이 같으면 복습 이력을 이어간다. 뒷받침되지 않거나 판정이 불명확하면 삭제한다. 과목 삭제에는 이 예외를 적용하지 않는다. 과목 대화는 삭제하지 않는다.
5) 복습 문제 삭제 시 학습 관찰, 복습 일정을 삭제한다. 삭제된 출처에 의존한 복습 기록은 복습 간격·이해 상태 계산에서 빼고, 그 출처와 함께 삭제·복원한다.
6) 대화만 삭제하면 노트는 유지되며, 대화 보관 기간은 대화 삭제일부터 3주다. 이후 노트를 삭제해도 보관 기간이 다시 시작되지 않는다.
7) 같은 자료에 기한이 여럿이면(휴지통 3주, 탈퇴 7일, 음성 7일) 가장 이른 기한에 삭제한다.

**비고**: [MVP] 3)은 v0.3.1 '과목 노트 삭제 시 전체 삭제'를 구체화한 것으로 영향이 큰 결정. 화면 용어는 '과목 삭제'.

## DAR-007 학습 자료 백업·복구

운영 > 복구 · 필수 · 담당 김민규 · 요청 · 관련 DAR-002, DAR-004

시스템은 노트·학습 상태·복습 일정을 합의된 기준에 따라 복구할 수 있어야 한다.

**수용 기준**

1) 격리 환경에서 복원한 뒤 소유권·버전·일정을 확인하고, 삭제 기록을 다시 적용한 다음에만 운영에 반영한다. 삭제 기록 누락 여부를 확인할 수 없으면 반영하지 않는다.
2) 백업 대상은 대화 기록과 과목 노트 업데이트 중간 상태를 포함한 모든 원본 데이터(데이터베이스, 객체 저장소)이며, 작업 큐·이벤트 전달처럼 원본에서 다시 만들 수 있는 데이터는 제외한다. 백업 보존 기간은 3주, 시점 복구 범위는 7일이다.
3) 음성은 백업에서도 원래 만료 시각(녹음 종료 + 7일)부터 접근·복원이 막히고, 실제 삭제는 DAR-001의 목표를 따른다. 복원으로 되살아나지 않는다.
4) 이미 삭제·만료된 자료는 어떤 복원에서도 다시 나타나지 않는다. 백업 사본은 보존 기간이 끝날 때 사라진다.
5) 삭제·취소 기록은 데이터베이스와 백업 밖의 추가 전용 보관소에 따로 보관하고, 모든 백업 사본보다 오래 유지한다.

**비고**: [MVP] v0.3.1 '음성데이터는 1주'를 3)으로 구체화. 복원 리허설 필요. v0.4.2: 2) 백업 대상을 원본 데이터로 명확히 하고, 5) 삭제 기록 보관 위치를 DB 밖으로 정함(ADR-0008).
