# 기능: 학습 노트

## SFR-008 과목별 종합 노트

학습 노트 > 과목 통합 · 필수 · 담당 이근욱 · 요청 · 관련 SFR-007, SFR-020, SFR-022, DAR-005

시스템은 같은 과목의 강의 내용을 종합 노트(과목 노트)에 누적 반영해야 한다.

**수용 기준**

1) 과목 노트를 메인 학습 공간으로 두며, 새 강의를 반영한 뒤에도 기존 관련 내용(사용자 작성·Q&A 보완 포함)을 유지한다.
2) 중복·상충을 구분해 표시한다.
3) 출처 강의 내용이 바뀌거나 삭제·이동되면 해당 블록에 '갱신 필요' 또는 '출처 삭제됨'을 표시하고, 그 블록을 Q&A·출제 근거에서 제외한다.
4) 새 강의 추가와 단순 수정은 자동으로 묶어 업데이트하고, 의미 충돌은 사용자 확인을 받는다.
5) 업데이트 실행 중에는 해당 과목 노트 편집을 막고(읽기는 허용), 실패·장기 대기·일시정지 시 편집을 다시 허용한다. 페이지 이동은 취소가 아니다.
6) 사용자는 업데이트를 일시정지(중간 결과 보존)하거나 취소(중간 결과 폐기)할 수 있다. 취소한 업데이트의 늦은 결과는 반영하지 않는다.

**비고**: [MVP] 과목 노트당 실행 중 1개·실패 후 재개 대기 1개·대기 요청 1개. 연속 실행 10분이 되면 일시정지 상태로 전환(초기값).

## SFR-009 직접 작성·수정

학습 노트 > 사용자 편집 · 필수 · 담당 이근욱 · 요청 · 관련 QUR-002, DAR-002

사용자는 학습 노트를 직접 작성하고 수정할 수 있어야 한다.

**수용 기준**

1) 저장 중·저장됨 상태를 표시하고, 서버 저장이 확인된 뒤에 '저장됨'으로 표시한다.
2) 저장 후 다시 열면 수정 내용이 유지된다.
3) 강의 노트와 과목 노트 모두 편집할 수 있다. 과목 노트는 업데이트 실행 중에만 편집이 막힌다(SFR-008).
4) 사용자가 편집한 AI 생성 블록은 보호 대상이 되어, 이후 자동 변경 시 사용자 확인을 거친다.
5) 강의 노트를 편집하면 그 내용을 근거로 쓰는 과목 노트 블록에 '갱신 필요'를 표시한다.
선택: 자동 저장 기능

**비고**: [MVP] STT 원본, 사용자 전사 정정, 강의 노트 편집은 서로 다른 버전 계열로 보관(DAR-002).

## SFR-010 출처와 변경 이력 조회

학습 노트 > 출처·이력 · 필수 · 담당 이근욱 · 요청 · 관련 DAR-002

사용자는 노트 내용의 근거와 변경 이력을 확인할 수 있어야 한다.

**수용 기준**

1) 출처를 강의 출처, 웹 출처(링크와 조회 시각), 일반 지식(출처 미확인)으로 구별해 표시하고, Q&A 보완분에는 출처 태그를 붙인다.
2) 변경 시각·이유·변경 전후를 확인한다.
3) '출처 삭제됨'과 '근거 미확인'을 구분한다.
4) 수정 후에도 이전 버전이 보존된다. 단, 정정 버전이 생긴 전사 구간의 STT 원본은 SFR-046 1)에 따라 삭제된다.
5) 이전 버전을 조회할 수 있고, 선택한 버전을 새 버전으로 복원할 수 있다.

**비고**: [MVP] v0.3.1의 '선택: 이전 버전의 조회·복원 범위'를 5)로 확정.

## SFR-011 과목·강의 노트 조회

학습 노트 > 보관함 · 필수 · 담당 이근욱 · 요청 · 관련 DAR-001, SER-002

사용자는 저장한 과목과 강의 노트를 다시 조회할 수 있어야 한다.

**수용 기준**

1) 선택한 과목·강의의 원문과 완료 노트를 표시한다.
2) 노트의 각 구간에서 해당 전사 위치로 이동할 수 있다.
3) 재접속 후에도 저장된 내용을 조회한다.
4) 다른 사용자의 자료는 조회되지 않는다.

**비고**: [MVP] 화면 아이디어: 과목·강의 노트 안에서 '@원문보기' 창으로 원문 이동.

## SFR-012 강의 소속 이동

학습 노트 > 보관함 · 권장 · 담당 이근욱 · 요청 · 관련 SFR-008, SFR-011

사용자는 강의를 다른 과목으로 이동할 수 있어야 한다.

**수용 기준**

1) 이동 후 새 소속에서 조회한다.
2) 녹음 당시 맥락 버전과 이력을 보존한다.
3) 이전 과목 노트에서는 해당 강의를 출처에서 빼 근거로 쓰지 않고, 새 과목 노트에서는 반영 후보로 표시한다.
4) 이동 직후 이전 과목의 요약이나 대화를 거쳐 이동한 강의 내용이 근거로 쓰이지 않는다.

**비고**: [후속] 정책은 확정, 출시 구현은 후속.

## SFR-013 노트 삭제

학습 노트 > 보관함 · 필수 · 담당 이근욱 · 요청 · 관련 SFR-048, DAR-006, SER-002

사용자는 자신의 노트를 삭제할 수 있어야 한다.

**수용 기준**

1) 삭제 전 함께 삭제될 범위를 자료 종류별 개수로 보여주고 확인받는다. 확인한 뒤 범위가 바뀌면 새 범위를 다시 보여준다.
2) 삭제한 노트는 조회·검색·신규 출제·Q&A 근거에 사용되지 않는다.
3) 삭제 전에 시작된 작업이 늦게 끝나도 삭제한 노트를 복원하거나 결과를 반영하지 않는다. 삭제 후 복원한 경우에도 그 이전 작업의 결과는 반영하지 않는다.
4) 삭제한 노트는 3주(21일)간 보관한 뒤 영구 삭제한다(복원은 SFR-048).
5) 즉시 영구 삭제도 가능하며, 2단계 확인과 함께 '복원할 수 없음, 백업에는 최대 약 3주 남을 수 있으나 어떤 복원에서도 다시 나타나지 않음'을 고지한다.
6) '과목 삭제'의 범위는 DAR-006을 따른다. 그 과목에 녹음 중이면 삭제할 수 없다.

**비고**: [MVP]

## SFR-014 학습 기록 내보내기

학습 노트 > 내보내기 · 권장 · 담당 이근욱 · 요청 · 관련 SFR-010

사용자는 완료된 강의 또는 과목 노트를 내보낼 수 있어야 한다.

**수용 기준**

1) 내보낸 내용이 선택한 완료 버전과 일치한다.
2) 원문 전사·노트·출처·이력을 포함한다.
3) 기본 형식은 Markdown이다.
4) 삭제된 자료와 다른 사용자의 자료는 포함하지 않으며, 음성은 포함하지 않는다.
선택: Markdown 외 추가 형식.

**비고**: [MVP]

## SFR-015 완료 노트 재작성

학습 노트 > 재생성 · 권장 · 담당 이근욱 · 요청 · 관련 SFR-022, QUR-004

사용자는 완료된 노트를 다시 작성하도록 요청할 수 있어야 한다.

**수용 기준**

1) 재작성 실패 시 기존 완료본을 유지한다.
2) 새 결과의 적용 여부와 버전을 구분한다.
3) 사용자 작성·Q&A 보완분은 SFR-022 기준에 따라 처리한다.
4) 과목 노트 내용만 새로 만들고 싶을 때는 삭제가 아니라 재작성을 쓰며, 기존 완료 버전은 보존된다.

**비고**: [MVP] 실패한 생성의 재시도는 SFR-043으로 분리.

## SFR-022 사용자·Q&A 보완 보존

학습 노트 > 재통합 · 필수 · 담당 이근욱 · 요청 · 관련 SFR-009, SFR-010

시스템은 노트 재생성 시 사용자 작성 내용과 Q&A 보완 내용을 처리해야 한다.

**수용 기준**

1) 유지·병합·충돌·무효화 결과를 구분한다.
2) 추가된 내용을 사용자에게 알리지 않고 덮어쓰거나 지우지 않는다.
3) 처리 결과를 이력에 남긴다.
4) 사용자 작성 블록은 원문 그대로 유지하고, Q&A 보완 블록은 기준이 된 내용이 사라지면 충돌로 표시한다.

**비고**: [MVP]

## SFR-043 실패한 생성 재시도

학습 노트 > 재생성 · 권장 · 담당 이근욱 · 요청 · 관련 SFR-007, QUR-004

사용자는 실패한 노트 생성을 다시 시도할 수 있어야 한다.

**수용 기준**

1) 실패한 단계와 사유를 표시한다.
2) 확보된 원자료로 실패한 단계부터 다시 실행한다. 과목 노트 업데이트는 저장된 중간 상태에서, 강의 최종 노트는 저장된 확정 전사에서, Q&A는 저장된 질문으로 새로 시도한다.
3) 재시도로 결과가 중복 반영되지 않는다.
4) 음성 보관 기간(7일)이 지나면 음성이 필요한 단계(재전사)는 재시도할 수 없음을 안내한다. 전사가 남아 있으면 요약 단계는 재시도할 수 있다.

**비고**: [MVP] SFR-015에서 분리. v0.4.3: 최종 노트 재시도 입력에서 구간 요약 제외(실시간 요약은 저장하지 않음, SFR-006 6)).

## SFR-047 노트 검색

학습 노트 > 보관함 · 권장 · 담당 이근욱 · 요청 · 관련 SFR-011, SFR-013

사용자는 키워드로 자신의 노트와 전사문을 검색할 수 있어야 한다.

**수용 기준**

1) 과목·강의 범위를 지정해 검색한다.
2) 검색 결과에서 해당 노트 블록이나 전사 위치로 이동한다.
3) 삭제한 자료와 다른 사용자의 자료는 결과에 나오지 않는다.

**비고**: [MVP] 한국어 검색 품질은 구현 검증 필요.

## SFR-048 삭제 노트 복원

학습 노트 > 보관함 · 권장 · 담당 이근욱 · 요청 · 관련 SFR-013, DAR-006

사용자는 삭제 후 보관 기간 안에 노트를 복원할 수 있어야 한다.

**수용 기준**

1) 보관 기간(3주) 안의 삭제 노트 목록을 확인한다.
2) 복원한 노트는 삭제 전 소속과 버전으로 돌아온다.
3) 보관 기간이 지난 노트는 복원할 수 없음을 안내한다.
4) 노트를 복원하면 그 삭제로 함께 삭제된 복습 문제·관찰·일정·대화만 함께 복원한다. 그 전에 따로 삭제된 항목은 삭제 상태를 유지한다.
5) 상위 항목이 휴지통에 있는 항목은 상위 항목을 먼저 복원하도록 안내한다.
6) 복원해도 취소된 업데이트는 자동 재개하지 않으며, 보관 기간이 지난 음성은 돌아오지 않는다.
7) 이해 상태는 복원된 관찰로 다시 계산한다.

**비고**: [MVP]
