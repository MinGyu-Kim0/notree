# 보안 요구사항

## SER-001 질문 원문 보관 범위

개인정보 > 최소 보관 · 필수 · 담당 임서연 · 요청 · 관련 DAR-003, QUR-003, QUR-007, SFR-045

시스템은 질문 원문을 대화 기록으로만 보관하고, 로그·작업 기록·관찰 등 다른 경로에 남기지 않아야 한다.

**수용 기준**

1) 질문 원문과 완료된 답변은 대화 기록으로 회원 탈퇴 시까지 보관하며, 대화 세션은 자동 만료되지 않는다.
2) 로그·오류 추적·작업 큐·실행 추적 기록에는 원문을 남기지 않고 작업 ID·시각·상태·오류 코드만 기록한다.
3) 관찰·요약을 통해 질문 속 개인 사실이나 문구를 우회 보관하지 않는다.
4) Q&A를 생성하는 도중의 데이터(미완성 답변, 프롬프트, 검색 후보)는 영구 저장하지 않는다. 완료된 답변, 노트 반영 결과, 관찰은 각 요구사항에 따라 저장한다.
5) 대화 삭제·탈퇴 시 원문은 SFR-045·DAR-006 기준으로 삭제된다.

**비고**: [MVP] v0.3.1 대비 대체: '지속 보관 금지'를 '대화 기록으로 보관, 다른 경로에는 금지'로 변경(Notion 2026-10-13 결정). 외부 AI 제공사의 보관은 COR-005. v0.4.3: 4)의 '중간 상태'를 생성 도중 데이터로 구체화(학습 상태·반영 결과 저장과 무관함을 명시).

## SER-002 자료·상태 접근 통제

접근 관리 > 사용자 경계 · 필수 · 담당 김민규 · 요청 · 관련 SFR-026, SFR-044

시스템은 노트·검색·복습·학습 상태를 올바른 사용자에게만 제공해야 한다.

**수용 기준**

1) 다른 사용자 식별자로 조회·변경·실행 결과에 접근할 수 없다.
2) 다른 사용자의 관찰이 개인화에 섞이지 않는다.
3) 사용자 범위 제한을 애플리케이션과 데이터베이스 양쪽에서 적용한다.

**비고**: [MVP] 개인용. 다른 사용자 자료 노출은 출시 차단 항목.

## SER-003 외부 서비스 키 보호

운영 > 비밀 정보 · 필수 · 담당 김민규 · 요청 · 관련 SIR-001, SIR-002

시스템은 외부 서비스 인증 정보를 사용자 화면·배포 파일·일반 로그에 노출하지 않아야 한다.

**수용 기준**

1) 화면·다운로드·오류 응답·로그·배포 이미지에서 키가 검출되지 않는다.
2) 외부 호출에 필요한 권한을 관리하며, 브라우저에는 외부 서비스 키를 전달하지 않는다.

**비고**: [MVP]

## SER-004 학습 데이터 전송 보호

통신 > 전송 보호 · 필수 · 담당 김민규 · 요청 · 관련 SFR-002, SFR-016

서비스는 공개 통신 구간에서 음성과 학습 데이터의 전송을 보호해야 한다.

**수용 기준**

1) HTTPS·WSS 등 암호화된 통신만 사용한다.
2) 암호화되지 않은 연결은 거부하고 상태를 안내한다.
3) 민감한 파일은 요청마다 로그인 상태를 확인하는 서버 경유로만 내려받게 한다.
