# 제약사항

## COR-001 서비스 실행 책임 분리

목표 구조 > 실행 환경 · 필수 · 담당 김민규 · 요청 · 관련 QUR-003

목표 서비스는 기존 기획의 Linux 환경에서 화면·API·장기 작업·데이터 보관 책임을 분리해야 한다.

**수용 기준**

1) 화면 연결과 장기 작업의 상태를 독립적으로 관리한다.
2) API·실시간 연결·작업 처리·예약 실행을 별도 프로세스로 나누고, 하나의 코드베이스와 PostgreSQL·객체 저장소로 시작한다.
3) 개발 환경은 Linux(WSL), 운영 환경은 Linux다.

**비고**: [MVP]

## COR-002 기획 기술 구성 준수

목표 구조 > 기술 선택 · 필수 · 담당 김민규 · 요청 · 관련 COR-001

목표 기술 구성은 기존 기획의 React·FastAPI·LangGraph·PostgreSQL을 기준으로 재확인해야 한다.

**수용 기준**

1) React·FastAPI·LangGraph·PostgreSQL을 채택한다.
2) 작업 큐는 Redis Streams 위에서 Taskiq(taskiq-redis RedisStreamBroker)로 구현한다. 작업 상태의 원본은 PostgreSQL에 두고, 전달할 작업은 PostgreSQL outbox에 함께 기록해 전달되지 못한 작업을 다시 보낸다.
3) LangGraph는 판단 분기와 여러 단계가 필요한 Q&A와 과목 노트 업데이트에 쓴다. LangGraph 체크포인터는 쓰지 않고, 과목 노트 업데이트는 DB의 단계 완료 기록으로 재개한다. 모델 호출은 OpenAI SDK로 직접 한다.
4) Redis와 Nginx를 채택한다. 화면 알림과 답변 스트리밍은 SSE, 녹음은 WebSocket으로 한다. GHCR은 필요할 때 선택한다. 검색은 PostgreSQL 안에서 pgvector(의미 검색)와 pg_bigm(키워드 검색)을 함께 쓴다.
5) 노트 편집기는 Tiptap으로 만든다.
6) 현재 구현의 구조·상한은 요구 근거로 쓰지 않는다.

**비고**: [MVP] v0.4.2: Procrastinate 대신 Redis Streams·asyncio 워커(2), ADR-0001). 변경 제안 ① 외부 브로커 사전 평가는 이 결정으로 종료, ② 알림 SSE·녹음 WebSocket 분리는 4)에 반영(ADR-0005). 이로써 10/6 배포 구조 문서와 SSE 사용이 다시 일치한다.
v0.4.3: LangGraph 사용 범위를 Q&A까지 넓히고 LangChain 없이 OpenAI SDK를 직접 씀(3), ADR-0009). pgvector 채택, 별도 벡터 DB는 쓰지 않음(4), ADR-0016).
v0.4.4: 직접 만드는 asyncio 워커 대신 Taskiq, 전달 누락 복구는 outbox(2), ADR-0017·0019). LangGraph 체크포인터 제거(3), ADR-0009). 편집기 Tiptap(5), ADR-0020).

## COR-003 검사 후 수동 운영 배포

운영 > 배포 · 권장 · 담당 김민규 · 요청 · 관련 DAR-007

목표 서비스는 기존 기획의 빌드 검사와 운영자 수동 배포 방식을 기준으로 배포 절차를 정의해야 한다.

**수용 기준**

1) 검사한 배포 버전을 이미지 식별자로 식별한다.
2) 애플리케이션과 데이터 변경의 복구 범위를 구분하며, DB 변경은 기존 버전과 호환되는 순서로 적용한다.
3) 빌드 검사 후 운영자가 수동으로 배포한다.
4) 배포 중에도 진행 중인 녹음은 기존 서버에서 끝까지 유지하고, 새 연결만 새 버전으로 보낸다.
5) 특정 클라우드에 종속되지 않는다.

**비고**: [MVP] v0.3.1 비고의 'AWS 제외'는 확정 제약이 아니며, 10/6 배포 문서(EC2 1대)와 충돌하지 않는다.

## COR-004 강의 녹음 허락 확인

법규 > 녹음 동의 · 필수 · 담당 전원 · 요청 · 관련 SFR-002, DAR-001

서비스는 강의 녹음 전 강의자의 녹음 허락과 제3자 음성이 포함된다는 점을 사용자가 확인하도록 해야 한다.

**수용 기준**

1) 첫 녹음 전 녹음 허락 확인 안내를 표시한다.
2) 사용자의 확인 기록을 남긴다.
3) 확인하지 않으면 녹음을 시작할 수 없다.

**비고**: [MVP] 안내 문구는 법률 확인 필요.

## COR-005 외부 AI 처리 고지·동의

법규 > 개인정보 · 필수 · 담당 전원 · 요청 · 관련 SIR-001, SIR-002

서비스는 음성·학습 데이터를 외부 AI 서비스로 보낸다는 사실과 대상을 사용자에게 알리고 동의를 받아야 한다.

**수용 기준**

1) 처리 위탁·국외 이전 대상(STT·LLM·메일 제공사), 항목, 보존 기간을 고지한다.
2) 동의하지 않으면 STT·AI·웹 검색 기능을 쓸 수 없음을 안내하고, 해당 외부 호출을 하지 않는다.
3) 제공사의 실제 처리 조건을 확인하지 못한 기능은 출시하지 않는다.
확인 필요: 개인정보 처리방침의 작성 범위.

**비고**: [MVP] 법률 확인 필요.
