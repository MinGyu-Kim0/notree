# 편집기는 Tiptap으로 직접 만들고, 블록 트리는 깊이를 붙인 평평한 순서로 저장한다

노트 편집기는 Notion처럼 모든 블록이 자식을 가질 수 있게 만든다(들여쓰기, 접고 펴는 보강 블록). BlockNote는 Tiptap 위에서 이 기능을 바로 주지만, 문서 형식이 BlockNote 블록 JSON으로 고정되고 일부 패키지(`@blocknote/xl-*`)가 GPL-3.0이다. 그래서 Tiptap(ProseMirror)으로 직접 만든다. 블록 ID는 공식 `@tiptap/extension-unique-id`(MIT)로 붙인다. 이 확장은 노드를 나누거나 합치거나 붙여 넣어도 ID를 유지하고, 생성 함수를 바꿔 UUIDv7을 만들게 한다(ADR-0013).

편집기 안의 블록은 트리인데, 노트 버전은 (블록, 리비전) 순서 목록이다(ADR-0007). 부모 ID를 저장하는 대신 전위 순서 목록에 깊이를 붙인다. 정보량이 같고 스택 하나로 서로 바뀐다. 깊이는 블록 리비전이 아니라 노트 버전 항목에 둔다. 들여쓰기와 이동은 내용 변경이 아니므로 새 리비전을 만들지 않고, 버전 비교와 되돌리기는 지금처럼 평평한 목록 비교로 끝난다.

## Consequences

- `note_versions.depths smallint[]`가 `block_revision_ids`와 같은 길이로 붙는다. 첫 항목의 깊이는 0이고, 각 항목은 앞 항목보다 최대 1까지만 깊을 수 있다. 서버가 검사한다.
- `block_revisions.content`는 자식을 뺀 그 노드 하나의 Tiptap JSON이다. 트리와 평평한 목록 사이 변환은 frontend(편집기 저장·불러오기)와 서버(AI가 만든 블록)에 하나씩 있다.
- 블록을 지우면 그 자식도 같은 노트 버전에서 함께 빠진다.
- 드래그 핸들, 슬래시 메뉴, 블록 노드 정의는 직접 만든다.
