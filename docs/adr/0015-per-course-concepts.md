# 개념과 이해 상태는 과목마다 따로 둔다

관찰, 이해 상태, 복습 단위는 모두 개념에 매달린다. AI가 뽑는 개념 이름은 "재귀", "재귀 함수", "recursion"처럼 제각각이라 같은 개념으로 묶는 기준이 필요하다. 사용자 전체에서 개념을 공유하면 한 과목에서 쌓은 이해가 다른 과목으로 이어지지만, 같은 이름이 과목마다 다른 뜻일 수 있고(자료구조의 '트리'와 생물학의 '트리'), 과목 삭제(DAR-006 3) 때 다른 과목도 쓰는 개념과 그 상태를 어디까지 지울지 모호해진다. 그래서 개념은 과목에 속하게 한다. 과목 안에서 정규화한 이름 `key`로 묶고, AI가 같은 개념이라 판단하면 `merged_into_id`로 합친다. 이해 상태도 (사용자, 과목의 개념)마다 하나다.

## Consequences

- 두 과목에 같은 개념이 나오면 이해 상태가 따로 쌓인다. 한 과목에서 '독립 수행 확인'이어도 다른 과목에서는 '미평가'로 시작한다.
- 과목을 지우면 그 과목의 개념, 관찰, 이해 상태, 복습 단위가 한 묶음으로 지워진다. 다른 과목에는 영향이 없다.
- 과목을 넘는 개념 연결이 필요해지면, 개념 테이블은 그대로 두고 과목 간 개념을 잇는 연결 테이블을 추가한다. 이해 상태 계산 규칙(SFR-025)을 바꿔야 하므로 그때 요구사항부터 고친다.
