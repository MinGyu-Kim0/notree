# 녹음 중 용어 적용은 STT 세션 교체로 한다

Soniox 실시간 API는 연결 도중 context(전문용어)를 바꾸는 방법을 제공하지 않는다. 그래서 사용자가 녹음 중 "용어 적용"을 누르면, 서버가 새 용어로 STT 연결을 하나 더 열고 음성을 그쪽으로 넘긴다. 음성은 이미 우리 서버를 거치므로 녹음 세션은 끊기지 않는다. 새 연결에는 교체 시점보다 2초 앞선 음성부터 보내 경계의 단어를 살린다. 옛 연결은 finalize 뒤 닫는다. 토큰 시각으로 두 전사를 이어 붙이고, 확신할 수 없는 겹침은 "중복 가능 구간"으로 표시한다. 교체는 사용자가 누를 때만, 최소 60초 간격으로 한다. 새 연결을 열지 못하면 옛 연결을 유지한다. 교체하는 순간에는 녹음 하나가 STT 동시 스트림을 2개 쓴다는 점을 계정 한도 산정에 넣는다.
