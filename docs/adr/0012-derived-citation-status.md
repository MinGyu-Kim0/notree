# '갱신 필요'와 '출처 삭제됨'은 저장하지 않고 버전 비교로 계산한다

블록의 근거가 바뀌면 '갱신 필요', 근거가 삭제되면 '출처 삭제됨'을 표시하고, 그 블록을 Q&A·출제 근거에서 빼야 한다(SFR-008 3). 근거가 바뀌는 경로는 전사 정정, 정정 되돌리기, STT 원본 삭제, 강의 노트 편집, 블록 삭제, 휴지통 이동·복원, 영구 삭제로 여럿이다. 상태를 열로 저장하면 이 경로마다 영향받는 블록을 찾아 상태를 바꾸는 코드가 필요하고, 하나라도 빠뜨리면 틀린 상태가 남는다. 그래서 근거 행에 인용 당시 버전(전사 구간의 정정 버전, 강의 노트 블록의 리비전)을 적어 두고, 조회할 때 원본의 현재 버전과 비교해 상태를 구한다. 원본 FK가 비었거나 원본이 휴지통에 있으면 '출처 삭제됨', 버전이 다르면 '갱신 필요'다.

## Consequences

- 상태를 퍼뜨리는 작업과 그 실패 처리가 없다. 블록 상태를 볼 때마다 근거와 원본을 조인하지만, 과목 노트 하나에 블록 수백 개 규모라 부담이 작다.
- STT 원본이 지워져도 근거는 원본(버전 0)을 가리키고 구간의 현재 버전은 정정 id라서, '출처 삭제됨'이 아니라 '갱신 필요'가 유지된다(SFR-046 1).
- 근거로 쓸 블록을 고르는 모든 경로(Q&A 검색, 출제, 반영 확인)는 같은 계산 함수를 거쳐야 한다. 이 함수는 `notebook` 모듈에 하나만 둔다.
- 규모가 커져 조회가 느려지면, 계산 결과를 캐시 테이블로 두고 원본 변경 때 다시 계산하는 쪽으로 바꾼다. 원본은 여전히 버전 비교다.
