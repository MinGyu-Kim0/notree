# 삭제 기록은 Postgres가 아니라 S3에 따로 보관한다

DAR-007은 백업을 복원한 뒤 삭제 기록을 다시 적용하고, 삭제 기록을 모든 백업보다 오래 유지하라고 한다. 삭제 기록을 같은 Postgres에 두면, 며칠 전 백업을 복원할 때 삭제 기록도 그 시점으로 돌아가 최근에 지운 자료가 되살아난다. 그래서 삭제 기록(내부 ID와 시각만, 내용 없음)을 버전 관리와 객체 잠금을 켠 S3 버킷에 추가 전용으로 쓴다. 삭제는 S3 기록이 확인된 뒤에 완료로 처리한다. 복원 절차는 "격리 환경에 백업 복원 → S3 삭제 기록 재적용 → 소유권·버전·일정 검증 → 운영 반영" 순서다. 탈퇴 삭제 기록(SFR-045 5)도 같은 곳에 둔다.
